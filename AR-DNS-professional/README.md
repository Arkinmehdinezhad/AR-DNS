# AR DNS

وب‌سایت معرفی سرویس DNS گیمینگ با طراحی فارسی، راست‌چین، واکنش‌گرا و افکت‌های تعاملی.

## مشاهده سایت

برای مشاهده آفلاین سایت، فایل `index.html` را با مرورگر باز کنید. نصب برنامه یا اجرای دستور خاصی لازم نیست.

> ابتدا پوشه را از فایل ZIP خارج کنید؛ سپس روی `index.html` دوبار کلیک کنید.

## تکنولوژی‌ها

- HTML5
- CSS3
- JavaScript
- فونت محلی کهربا
- فایل‌های SVG محلی

## ویرایش پروژه

- محتوای صفحه: `index.html`
- طراحی اصلی: `css/main.css`
- انیمیشن‌ها: `css/animations.css`
- رفتارهای تعاملی: `js/main.js`
- فونت: `assets/fonts/`
- لوگوهای بازی‌ها: `assets/logos/`
- تصاویر عمومی و آیکن سایت: `assets/images/`

جزئیات کامل پوشه‌ها در فایل `docs/PROJECT-STRUCTURE.md` نوشته شده است.

## ویژگی‌ها

- رابط فارسی و راست‌چین
- طراحی گیمینگ نئونی
- HUD پینگ و نمودار اتصال
- کارت‌های تعاملی دسکتاپ
- افکت حرکتی موس
- لوگوهای بازی‌ها
- منوی موبایل
- کاهش افکت‌های سنگین در موبایل
- اجرای کاملاً آفلاین
