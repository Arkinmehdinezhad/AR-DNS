## درباره پروژه

**AR DNS** یک لندینگ‌پیج فارسی و راست‌چین برای معرفی سرویس DNS گیمینگ است. رابط کاربری پروژه با حال‌وهوای نئونی و گیمینگ طراحی شده و شامل HUD زنده پینگ، نمایش وضعیت اتصال، کارت‌های تعاملی، انیمیشن‌های نرم و بخش بازی‌های پشتیبانی‌شده است.

این نسخه کاملاً مستقل است و برای اجرا به Node.js، نصب پکیج یا اتصال اینترنت نیاز ندارد؛ بعد از دانلود و Extract کردن پروژه، تنها با باز کردن فایل `index.html` اجرا می‌شود.

> [!NOTE]
> مقادیر پینگ و وضعیت شبکه در این نسخه نمایشی هستند و برای نمایش رابط کاربری شبیه‌سازی شده‌اند.

## ویژگی‌ها

- طراحی مدرن با تم گیمینگ و رنگ‌های نئونی
- رابط کاملاً فارسی و راست‌چین (RTL)
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- جلوگیری از اسکرول افقی در موبایل و هنگام Zoom Out
- HUD تعاملی پینگ و نمودار اتصال
- افکت نور دنبال‌کننده نشانگر موس
- کارت‌ها و بخش‌های دارای انیمیشن هنگام اسکرول
- منوی موبایل و پیمایش نرم بین بخش‌ها
- نمایش بازی‌های محبوب مانند Valorant، Fortnite، PUBG و CS2
- فونت و تمام Assetها به‌صورت محلی
- اجرای کاملاً آفلاین و بدون وابستگی

## اجرای پروژه

### روش سریع و آفلاین

1. پروژه را دانلود کنید.
2. اگر فایل به‌صورت ZIP است، آن را Extract کنید.
3. فایل `index.html` را با مرورگر باز کنید.

همین! هیچ دستور یا نصب اضافه‌ای لازم نیست.

### اجرا با Live Server

برای توسعه راحت‌تر می‌توانید پوشه پروژه را در VS Code باز کرده و با افزونه **Live Server** اجرا کنید.

## ساختار پروژه

```text
AR-DNS/
├── index.html                 # صفحه اصلی و نقطه ورود سایت
├── README.md                  # معرفی و راهنمای پروژه
├── css/
│   ├── main.css               # طراحی اصلی و Responsive
│   └── animations.css         # انیمیشن‌ها و افکت‌ها
├── js/
│   └── main.js                # تعاملات و رفتارهای سایت
├── assets/
│   ├── fonts/
│   │   └── kahroba-fd-bl.ttf  # فونت فارسی
│   ├── images/
│   │   └── favicon.svg        # آیکن سایت
│   └── logos/                 # لوگوهای بازی‌ها
└── docs/
    └── PROJECT-STRUCTURE.md    # توضیحات کامل ساختار پروژه
```

## شخصی‌سازی

- برای تغییر متن‌ها و بخش‌های صفحه، فایل `index.html` را ویرایش کنید.
- برای تغییر رنگ‌ها، فاصله‌ها و چیدمان، به `css/main.css` بروید.
- انیمیشن‌ها در فایل `css/animations.css` قرار دارند.
- رفتارهای تعاملی سایت از طریق `js/main.js` کنترل می‌شوند.
- لوگو، فونت و تصاویر را می‌توانید از پوشه `assets` جایگزین کنید.
